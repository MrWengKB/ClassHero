<h1>课堂英雄</h1>

追踪任务完成情况，课堂活动加分，阅读记录，等等。
查看学生进度、班级排行榜。
用Google Sheets存储数据。

页面左上角可以切换界面语言：华文、English、Melayu、தமிழ்。

---

<h2>Class Heroes</h2>

Track task completion, award points for class activities, log reading, and more.
See each student's progress and the class leaderboard.
Data is stored in Google Sheets.

Switch the interface language at the top left of the page: 华文, English, Melayu, தமிழ்.

---

<h2>Wira Kelas</h2>

Jejaki penyiapan tugasan, beri mata untuk aktiviti kelas, rekod bacaan dan banyak lagi.
Lihat kemajuan setiap murid dan papan pendahulu kelas.
Data disimpan dalam Google Sheets.

Tukar bahasa paparan di bahagian atas kiri halaman: 华文, English, Melayu, தமிழ்.

<h2>வகுப்பறை நாயகர்கள்</h2>

பணிகள் முடிந்ததைக் கண்காணிக்கலாம், வகுப்புச் செயல்பாடுகளுக்குப் புள்ளிகள் வழங்கலாம், வாசிப்பைப் பதிவு செய்யலாம், இன்னும் பல.
ஒவ்வொரு மாணவரின் முன்னேற்றத்தையும் வகுப்புத் தரவரிசையையும் பார்க்கலாம்.
தரவு Google Sheets-இல் சேமிக்கப்படுகிறது.

பக்கத்தின் மேல் இடப்பக்கத்தில் இடைமுக மொழியை மாற்றலாம்: 华文, English, Melayu, தமிழ்.
