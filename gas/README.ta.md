# தரவை Google Sheets-இல் சேமித்தல்

1. புதிய Google Sheet ஒன்றை உருவாக்குங்கள் (எந்தப் பெயரும் சரி, எ.கா. "வகுப்பறை நாயகர்கள் தரவு").
2. **Extensions → Apps Script** மெனுவைத் திறந்து, எடிட்டரில் ஏற்கனவே உள்ள குறியீட்டை நீக்கி, இந்தக் கோப்புறையில் உள்ள `Code.gs` முழுவதையும் ஒட்டி, Ctrl+S அழுத்திச் சேமியுங்கள்.
3. மேல் வலப்பக்கத்தில் **Deploy → New deployment** அழுத்தி, வகையாக **Web app** என்பதைத் தேர்ந்தெடுங்கள்:
   - Execute as: **Me** (நான்)
   - Who has access: **Anyone** (எவரும்)
4. **Deploy** அழுத்தி, கேட்கும்போது அனுமதி கொடுங்கள். "Google hasn't verified this app" என்று காட்டும். **Advanced → Go to … (unsafe)** அழுத்துங்கள். இது உங்கள் சொந்த ஸ்கிரிப்ட்.
5. கிடைக்கும் **Web app URL**-ஐ (`/exec` என முடியும்) நகலெடுத்து, `js/config.js`-இல் உள்ள `API_URL = '…'` மேற்கோள்களுக்குள் ஒட்டி, சேமித்துப் பதிவேற்றுங்கள்.

பிறகு இணையதளத்தில் புதிய கணக்கைப் பதிவு செய்யுங்கள். மேகக்கணிக் கணக்குகள், உலாவியில் சேமிக்கப்பட்ட பழைய கணக்குகளிலிருந்து தனியானவை.
அதே கணினியில் அதே பயனர் பெயரில் பதிவு செய்தால், உலாவியில் முன்பு சேமிக்கப்பட்ட தரவு தானாக Sheet-க்கு மாற்றப்படும்.

`Code.gs`-ஐ மாற்றும் ஒவ்வொரு முறையும் **Deploy → Manage deployments → Edit → Version: New version** மூலம் மீண்டும் deploy செய்யுங்கள். URL மாறாது.

பின்வரும் தாள்கள் (tabs) தானாக உருவாகும். ஸ்கிரிப்ட் அவற்றைச் சீன மொழிப் பெயர்களில் உருவாக்குவதால் சில பெயர்கள் சீன மொழியில் இருக்கும்:
- `teachers`: கணக்குகள் (கடவுச்சொற்கள் உப்பிட்ட hash ஆக மட்டுமே சேமிக்கப்படும், எளிய உரையாக அல்ல)
- `data`: ஒவ்வொரு ஆசிரியரின் முழுத் தரவு (நிரல் பயன்படுத்துவது, கையால் திருத்த வேண்டாம்)
- `Points overview` (புள்ளி மேலோட்டம்): ஒவ்வொரு மாணவரின் ஒவ்வொரு செயல்பாட்டுக்குமான எண்ணிக்கையும் புள்ளிகளும். நேரடியாகப் பார்க்கலாம், வடிகட்டலாம், விளக்கப்படம் வரையலாம்.
- `classes`: எந்த tab எந்த வகுப்புக்குரியது (நிரல் பயன்படுத்துவது)
- **ஒவ்வொரு வகுப்புக்கும் இரண்டு tabs**: எ.கா. "4A" புள்ளிகளுக்கு (மாணவர்கள், ஒவ்வொரு செயல்பாட்டின் எண்ணிக்கை, மொத்தம்), "4A · Reading" வாசிப்புப் பதிவுக்கு (தற்போதைய முன்னேற்றம், முடித்த சுற்றுகள், மொத்தப் புத்தகங்கள், கடைசிப் பதிவு). இரண்டும் தனியானவை. வகுப்பை உருவாக்கிய சில வினாடிகளில் தோன்றும், வகுப்பின் பெயர் மாற்றப்பட்டாலோ நீக்கப்பட்டாலோ அவையும் மாறும். இவை நிரலால் உருவாக்கப்படுபவை, பார்ப்பதற்கு மட்டும். கையால் செய்த மாற்றங்கள் அடுத்த முறை சேமிக்கும்போது மேலெழுதப்படும்.
- **தாள் மொழி**: tab பெயர்களும் தலைப்புகளும் இயல்பாக ஆங்கிலத்தில் உள்ளன. `Code.gs`-இல் மேலே உள்ள `const SHEET_LANG = 'en';`-ஐ `'ta'` (தமிழ்), `'zh'` (சீனம்) அல்லது `'ms'` (மலாய்) என மாற்றுங்கள். சேமித்து, மீண்டும் deploy செய்யுங்கள் (Deploy → Manage deployments → Edit → Version: New version). சொற்களை மாற்ற, அதன் கீழே உள்ள `SHEET_LABELS`-ஐத் திருத்துங்கள். பழைய பெயருள்ள tabs அடுத்த முறை தரவு சேமிக்கும்போது தானாகப் பெயர் மாறும்.

> `Code.gs`-ஐப் புதுப்பித்த பிறகு, புதிய பதிப்பை deploy செய்ய மறக்காதீர்கள் (படி 5-க்குப் பிறகு உள்ள குறிப்பைப் பாருங்கள்).
