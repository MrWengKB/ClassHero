# Store data in Google Sheets

1. Create a new Google Sheet (any name, e.g. "Class Heroes data").
2. Open **Extensions → Apps Script**, delete the code already in the editor, paste in everything from `Code.gs` in this folder, and press Ctrl+S to save.
3. At the top right, click **Deploy → New deployment** and choose the type **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
4. Click **Deploy** and authorise when asked. You will see "Google hasn't verified this app". Click **Advanced → Go to … (unsafe)**. This is your own script.
5. Copy the **Web app URL** (it ends in `/exec`), paste it between the quotes of `API_URL = '…'` in `js/config.js`, then save and upload.

After that, register a new account on the website. Cloud accounts are separate from the old accounts stored in the browser.
If you register on the same computer with the same username, the data previously stored in the browser is moved to the Sheet automatically.

Whenever you change `Code.gs`, redeploy it with **Deploy → Manage deployments → Edit → Version: New version**. The URL stays the same.

These sheets (tabs) are created in the spreadsheet automatically. Their names are in Chinese because the script creates them that way:
- `teachers`: accounts (passwords are stored only as salted hashes, never as plain text)
- `data`: each teacher's full data (used by the program, please do not edit by hand)
- `Points overview`: each student's count and points for every activity. You can view, filter and chart it directly.
- `classes`: which tab belongs to which class (used by the program)
- **Two tabs per class**: e.g. "4A" holds points (students, count per activity, total), and "4A · Reading" holds the reading log (current progress, rounds completed, total books, last check-in). The two are independent. They appear a few seconds after a class is created, and are renamed or deleted along with the class. These tabs are generated by the program and are for viewing only. Manual edits are overwritten the next time data is saved.
- **Sheet language**: tab names and headers are in English by default. Open `Code.gs` and change `const SHEET_LANG = 'en';` near the top to `'zh'` (Chinese), `'ms'` (Malay) or `'ta'` (Tamil). Save, then redeploy (Deploy → Manage deployments → Edit → Version: New version). To change the wording, edit `SHEET_LABELS` just below it. Tabs with old names are renamed automatically the next time data is saved.

> After updating `Code.gs`, remember to deploy a new version (see the note after step 5).
