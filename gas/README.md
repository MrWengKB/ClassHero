# 把数据存到 Google Sheet

1. 新建一个 Google Sheet（名字随意，比如「课堂英雄数据」）。
2. 菜单「扩展程序 → Apps Script」，删掉编辑器里原有的代码，把本文件夹里 `Code.gs` 的全部内容贴进去，按 Ctrl+S 保存。
3. 右上角「部署 → 新建部署」，类型选「网页应用」：
   - 执行身份：**我**
   - 谁可以访问：**任何人**
4. 点「部署」，按提示授权（会出现“Google 尚未验证此应用”，点「高级 → 转至…（不安全）」，这是你自己的脚本）。
5. 复制得到的「网页应用网址」（以 `/exec` 结尾），粘贴到 `js/config.js` 的 `API_URL = '…'` 引号里，保存并上传。

之后在网站上重新注册账号即可（云端账号和以前浏览器里的账号是分开的）。
如果用同一台电脑、同一个用户名注册，以前存在浏览器里的数据会自动搬到 Sheet 上。

以后修改了 `Code.gs`，要在「部署 → 管理部署 → 编辑 → 版本：新版本」重新部署，网址不变。

表格里会自动出现三个工作表：
- `teachers`：账号（密码只存加盐哈希，不是明文）
- `data`：每位老师的完整数据（程序用，请不要手动改）
- `积分总览`：每个学生每项活动的次数和分数，可以直接查看、筛选、做图表
